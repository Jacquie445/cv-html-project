# CV HTML Sémantique

Projet de CV one-page réalisé uniquement en HTML5, dans le cadre d'une révision sur roadmap.sh.

## Objectif

Créer un CV structuré, accessible et optimisé pour le web, en utilisant uniquement le HTML (sans CSS ni JavaScript).

## Exigences respectées

- **HTML sémantique** : utilisation de balises telles que `<header>`, `<main>`, `<section>`, `<article>`, `<address>`
- **Balises méta SEO** : title, description, keywords, author
- **Balises Open Graph (OG)** : og:title, og:description, og:type, og:url
- **Favicon** : ajoutée dans le `<head>`

## Structure du CV

- En-tête (nom, poste, coordonnées)
- Compétences
- Formation
- Expérience professionnelle
- Liens (LinkedIn, GitHub)
